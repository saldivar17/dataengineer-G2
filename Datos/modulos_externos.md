# Modulos externos

## Entornos virtuales

### Crear el entorno virtual

```bash
python -m venv 'nombre_del_entorno'
```

### Activar el entorno virtual

```bash
# windows CMD/Powershell
nombre_del_entorno\Scripts\activate
# MacOS/Linux
source nombre_del_entorno\Scripts\activate
#para desactivar
deactivate
```
